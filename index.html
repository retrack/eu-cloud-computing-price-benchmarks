EU Storage Price Benchmarks

Cloud storage list prices from the vendors' own pricing pages, normalised so the numbers are actually comparable: one hour basis, one unit, one currency — euros per GiB per month, 730 hours, Frankfurt or the closest region each vendor operates. Three series, read separately: object storage priced on the data you store, block storage priced on the capacity you provision, and file storage — shared file systems several machines mount at once — where the floor a vendor will sell you often matters more than the rate.

The three series are kept apart in that file: a euro per GiB of data stored, a euro per GiB of capacity provisioned and a euro per GiB held on a shared file system are different quantities and must never share an axis.

How to read a run

Published storage prices are not comparable as printed. Three things differ between vendors and quietly move the figure by 10 % or more:

  • The unit. Several vendors bill in binary units while printing “GB”; others state no basis at all. Decimal versus binary is a 7.4 % difference on the same physical bytes. Rows whose vendor never states a basis carry a △ marker and follow the page's unit selector.
  • The month. Hourly-billed vendors are extrapolated using 720, 730 or 744 hours depending on who does the extrapolating. This benchmark uses 730 throughout, and the selector lets you change it.
  • What the headline excludes. For object storage: egress, requests, retrieval fees, minimum storage durations and minimum billable object sizes. For block storage: provisioned IOPS, provisioned throughput and snapshots, which at the top of the range cost several times the capacity itself. Both are shown alongside the storage rate.

Anything a vendor does not publish is shown as not published, never estimated, and a scenario total containing one is prefixed ≥ rather than silently treated as zero.

The three series answer different questions and their numbers do not compare. Object storage bills the bytes you actually hold; block storage bills the size of the volume, empty or full. A block volume also carries a performance ceiling, so a cheap row is not a substitute for an expensive one unless it can serve the workload — the block pages mark the rows that cannot. File storage adds a third trap: several vendors will not sell a share below a minimum size, so asking for less does not make the row cheaper, it makes the price per gigabyte worse. Its ceilings are rarely flat numbers either — most vendors sell the IOPS and the throughput with the gigabytes — so the file storage page states each limit at the size being billed rather than quoting a maximum reached only at 100 TiB.

Treat this as a starting point for your own verification, not as an authority — list prices ignore negotiated discounts and commitment terms, which are where large deals are actually decided.
